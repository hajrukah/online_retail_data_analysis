# Cleaned Online Retail Dataset

## Project
Online Retail Sales Analysis — Swynex Data Analytics Internship.

## Dataset Information
- Source: Kaggle Online Retail dataset
- Cleaning tool: Microsoft Excel and Power Query
- Final row count: 392,692
- Number of columns: 9

## Cleaning Summary
The dataset was prepared by:
- Removing duplicate records
- Removing cancelled invoices
- Removing records with missing Customer IDs
- Removing non-positive quantities and unit prices
- Cleaning text fields
- Creating a Revenue column using Quantity × UnitPrice
